# tripwire in build-blocklist.sh. That tripwire refuses any build containing a
# host in the Tranco top 10,000, because a host that widely used is usually a
# feed error. Usually is not always: a convincing typosquat earns its traffic by
# being mistaken for something popular, so the most dangerous entries can be the
# most popular ones. This file is where that judgement is recorded, so the
# tripwire stops asking about a case that has already been decided.

# AN ENTRY HERE KEEPS A HOST BLOCKED. It is the opposite of an allowlist entry
# in every respect, including which way it fails: if this file is wrong, users
# see a banner on a site that works, and can override it per tab. That is the
# recoverable direction, which is why the bar here is lower than for
# blocklist-allow.txt -- but a reason is still required, because "we looked at
# this and decided" is the entire value of the file.
#
# Format: one host per line. Blank lines and lines beginning with # ignored.
# Inline # comments carry the reason.
